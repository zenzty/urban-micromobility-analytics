# Project Work

As part of the project work, students are required to create an interactive data visualization dashboard using a freely chosen dataset.

The purpose of the dashboard is to effectively support the exploration and analysis of the selected dataset; therefore, simply displaying static charts is not sufficient.

## Minimum Requirements

The dashboard should:
* contain several types of meaningful data visualizations;
* include interactive features that support data analysis, such as filtering, searching, selection, hover information, zooming, or linked views;
* allow users to examine the data from different perspectives;
* use at least one visualization library listed on [PyViz.org](https://pyviz.org/);
* not rely exclusively on traditional bar, line, and pie charts.

Chart types should always be selected according to the characteristics of the data and the analytical questions being investigated. Variety is not a goal in itself: the visualizations should support the analysis and interpretation of the data.

## Data Preparation

Data preparation is also an important part of the project. This may include, for example:
* cleaning the data;
* handling missing or erroneous values;
* converting data types;
* creating categories or derived variables;
* aggregating data;
* combining multiple data sources;
* restructuring the data into a format suitable for visualization.

The source of the dataset must be clearly indicated.

## Assessment Criteria

The project will be assessed according to the following criteria:

* **Data Preparation:** The extent and quality of the data processing and preparation carried out on the selected dataset.
* **Design Process:** The overall structure and coherence of the dashboard, the clarity of the analytical questions, and the consistency of the visual design.
* **Quality of Visualizations:** The appropriate choice of visualization types, their readability, visual quality, and diversity.
* **Analytical Capabilities:** The usefulness of filtering, searching, selection, and other interactive features, as well as the extent to which the dashboard supports meaningful exploration and comparison of the data.
* **Technical Implementation:** The functionality and stability of the dashboard, as well as the appropriate use of the selected visualization library or libraries.

## Project Presentation / Defense

* The student should be able to present the dataset, explain the main steps of data preparation, describe the most important design decisions, demonstrate how the dashboard works, and discuss the key insights that can be derived from the visualizations.
* During the presentation, the student should formulate the most important analytical questions that the dashboard is designed to address and demonstrate how the implemented visualizations and interactive features support the investigation of these questions.

## Submission

The project must be submitted through this submission point on the e-learning platform.

The submission can be made either by:
* uploading the complete project as a ZIP file, or
* providing the link to the project's GitHub repository.

# Projektmunka

A projektmunka során egy interaktív adatvizualizációs dashboardot kell elkészíteni egy szabadon választott adathalmaz felhasználásával.

A dashboard célja, hogy a kiválasztott adathalmaz feltárását és elemzését hatékonyan támogassa, ezért nem elegendő pusztán statikus diagramok megjelenítése.

## Minimális követelmények

A dashboard:
* többféle érdemi adatvizualizációt tartalmazzon;
* tartalmazzon az adatok elemzését segítő interaktív funkciókat, például szűrést, keresést, kijelölést, hover információkat, zoomolást vagy egymással összekapcsolt nézeteket;
* tegye lehetővé, hogy a felhasználó az adatokat különböző szempontok szerint vizsgálhassa;
* legalább egy, a [PyViz.org](https://pyviz.org/) oldalon felsorolt vizualizációs könyvtárat használjon;
* ne kizárólag hagyományos oszlop-, vonal- és kördiagramokra épüljön.

A diagramok típusát minden esetben az adatokhoz és a vizsgált kérdéshez célszerű megválasztani. A változatosság önmagában nem cél: a vizualizációknak az elemzést és az adatok értelmezését kell támogatniuk.

## Adatelőkészítés

A projekt része az adatok előkészítése is. Ide tartozhat például:
* az adatok tisztítása;
* hiányzó vagy hibás értékek kezelése;
* adattípusok átalakítása;
* kategóriák vagy új változók létrehozása;
* aggregálás;
* több adatforrás összekapcsolása;
* az adatok vizualizációhoz megfelelő struktúrába rendezése.

Az adathalmaz forrását egyértelműen fel kell tüntetni.

## Értékelési szempontok

A projekt értékelésénél az alábbi szempontokat vesszük figyelembe:

* **Adatelőkészítés:** Az adathalmazon végzett feldolgozó és előkészítő munka mennyisége és minősége.
* **Tervezési folyamat:** A dashboard felépítésének átgondoltsága, a vizsgált kérdések egyértelműsége és a vizuális struktúra következetessége.
* **Vizualizációk minősége:** A diagramtípusok megfelelő megválasztása, olvashatósága, vizuális minősége és változatossága.
* **Elemzési lehetőségek:** A szűrési, keresési, kijelölési és egyéb interaktív funkciók hasznossága, valamint az, hogy a dashboard mennyire támogatja az adatok tényleges feltárását és összehasonlítását.
* **Technikai megvalósítás:** A dashboard működése, stabilitása, valamint a választott vizualizációs könyvtár vagy könyvtárak megfelelő használata.

## Védés

* A hallgató legyen képes bemutatni az adathalmazt, az adatelőkészítés lépéseit, a fontosabb tervezési döntéseket, a dashboard működését, valamint az elkészített vizualizációk segítségével levonható legfontosabb következtetéseket.
* A védés során a hallgató fogalmazza meg azokat a legfontosabb elemzési kérdéseket, amelyek megválaszolását a dashboard támogatja, és mutassa be, hogy az elkészített vizualizációk és interaktív funkciók hogyan segítik ezek vizsgálatát.
